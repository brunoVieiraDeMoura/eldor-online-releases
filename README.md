# Eldor Online

Arquivos de lançamento do **Eldor Online** (RPG online em alpha fechado).

- **Para jogar**: baixe o `EldorLauncher.exe` em [Releases](../../releases/latest). Ele baixa o jogo, mantém atualizado e abre.
- **Conta e acesso ao alpha**: https://eldor-online.vercel.app

Este repositório guarda só os arquivos prontos do jogo e as novidades que o launcher mostra. O código-fonte não fica aqui.
